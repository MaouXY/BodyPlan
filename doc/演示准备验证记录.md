## 测试内容

后端：

- `ProfilePreviewTest`：4 项，未保存数据的预览、不同输入产生不同建议、缺失数据拒绝、读取已有档案不重复插入。
- `ProfileWorkflowServiceTest`：3 项，建档/体能/计划顺序与提交、推荐失败回滚、依赖失败停止后续操作并回滚。
- `RecommendationDemoTest`：2 项，伤病/器械限制排除与清空后的变化、空动作库拒绝生成。
- `CheckinDemoTest`：4 项，自由训练真实反馈、重复自由打卡拦截、未来训练日拒绝打卡、过去日期不显示成下次训练日。

事务测试通过 Spring 实际事务拦截器和记录型事务管理器验证提交/回滚边界；不等同于 MySQL 集成测试。MySQL 持久化联动由使用者按验收清单检查。

Android `DemoFlowTest`：

- 已建档但缺体能测试返回问卷。
- 未完成档案始终返回问卷。
- 档案与体能齐全可进入主页，没有计划时允许生成。
- 失败响应不转换成空计划；成功的空计划响应可正确识别。
- 必需数据缺失时报错。
- 自由打卡正确发送实际时长、感受与中文备注，不误带计划动作或整次时长。

## 可复现命令

后端目录：

```powershell
mvn -q "-Dtest=ProfileWorkflowServiceTest,ProfilePreviewTest,RecommendationDemoTest,CheckinDemoTest" package
```

未执行连接本地库的 `BodyPlanApiApplicationTests`，也未执行会注册账号/写入数据的模拟器闭环测试。

管理端目录：

```powershell
npm run build
```

Android 目录：

```powershell
.\gradlew.bat --no-daemon :app:assembleDebug :app:compileDebugAndroidTestKotlin
.\gradlew.bat --no-daemon :app:testDebugUnitTest "-PbodyplanBuildDir=$env:TEMP\bodyplan-demo-build"
```

本机默认中文构建路径下，JUnit 进程曾报告找不到已经编译出的测试类。使用 `bodyplanBuildDir` 将测试产物写到临时英文目录后通过；源码不移动，默认 APK 路径不变。测试命令请保留这个参数。`bodyplanBuildDir` 只作用于传入该参数的本次构建。

报告：

- 后端：`BodyPlanApi/target/surefire-reports/`。
- Android：`%TEMP%/bodyplan-demo-build/reports/tests/testDebugUnitTest/index.html`。
- APK：`BodyPlanApp/app/build/outputs/apk/debug/app-debug.apk`。
- Web：`BodyPlanWeb/dist/`。
